# OdiaType — Unicode ↔ Akruti Sarala Converter

A React + Vite browser app for converting Odia text between Unicode and the **Akruti Sarala legacy encoding**.

## Run locally (Windows)

1. Install Node.js LTS from https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open Terminal in that folder and run:

```bash
npm install
npm run dev
```

5. Open the local URL Vite prints (usually `http://localhost:5173`).

## Push to GitHub

1. Create an empty repository on GitHub.
2. Open this project folder in VS Code (the folder containing `package.json`).
3. Open the VS Code terminal and run:

```bash
git init
git add .
git commit -m "Initial OdiaType project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the remote URL with your own GitHub repository URL. If Git says the remote already exists, run `git remote set-url origin YOUR-REPOSITORY-URL` and then push again.

**Important:** Do not upload `node_modules` or `dist`. The included `.gitignore` excludes them automatically. Commit `package-lock.json` so installs are reproducible.

## Build for deployment

```bash
npm run build
npm run preview
```

The production website is generated in `dist/`. You can deploy this folder to Vercel or Netlify. For Vercel, import the project repository and keep the default Vite settings:
- Build command: `npm run build`
- Output directory: `dist`

## Troubleshooting

- If `vite is not recognized`, first run `npm install` in the project root.
- If JSX reports `React is not defined`, confirm the included `vite.config.js` exists and restart the dev server.
- Use Node.js LTS. If dependencies become corrupted, delete `node_modules` and `package-lock.json`, then run `npm install` again.

## What is included

- Unicode Odia → Akruti Sarala legacy text (reverse lookup)
- Akruti Sarala legacy text → Unicode Odia
- Live conversion
- Copy result
- Download output as `.txt`
- Upload a `.txt` input file
- Character and word count
- Responsive layout
- Browser-only processing; no API or database required

## Important compatibility note

“Akruti” is not one universal encoding. Different Akruti font families and versions can have different character maps. This starter uses the published **Akruti Sarala** mapping, not every Akruti Oriya font. The project does not include a proprietary Akruti font file. If you need the output to visually render in a legacy DTP application, install the exact matching licensed Akruti Sarala font on that computer.

The Unicode → Akruti direction is generated by reversing the published map. Some Unicode sequences can have more than one legacy representation, so inspect the output before using it in print. This is a useful starter implementation, not a claim of 100% press-grade conversion.
